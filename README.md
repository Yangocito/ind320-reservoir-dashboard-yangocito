# IND320 Reservoir Dashboard

This repository contains my compulsory IND320 project work based on reservoirs.csv.

## Run locally

    python -m pip install -r requirements.txt
    streamlit run app.py

The app reads data/reservoirs.csv locally. The four Streamlit pages are:

1. Home
2. Imported data
3. Reservoir measurements
4. About this project

The notebook IND320_reservoirs_analysis.ipynb contains the Pandas import,
English header names, previews, plots, AI-use statement and the compulsory log.
